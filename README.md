# Compressed-Map-Data (.CMD)
A map compression for ts-map, created for HiQ-NAV.

Allows for tiles to be compressed to resolve issue with high space usage because of clusters/sectors formation on Windows.

## Issues

I am aware of the current issue regarding the .NET Version and the possible issue of XWMS, resulting in a crash of the application. I am working on getting the .NET 6.0 version ready. For XMWS updates, see [XWMS](https://github.com/miyumelu/next-window-management-system)

Made for [ts-map](https://github.com/dariowouters/ts-map) and [HiQ-NAV](https://github.com/miyumelu/HiQ-NAV)
